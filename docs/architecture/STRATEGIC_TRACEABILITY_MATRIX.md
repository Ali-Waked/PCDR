## 1. Purpose and rules

- Trace strategic intent to architecture: **Strategic Plan chapter → Objective → Pillar → Program/Activity → Business capability → System module → Data entities → Workflow → Roles/permissions → Reports/indicators/KPIs → Implementation phase**.
- **No overclaim rule:** A generic CRUD/module shell does **not** equal full coverage of a humanitarian domain. Coverage is marked only where entities, workflow, permissions, privacy controls, reporting, and dependencies are adequately specified.
- **Governance rule:** OQ-49 is **PARTIALLY RESOLVED — PENDING FORMAL APPROVAL**. ADR-001–017 remain **PROPOSED**. No Phase 2 start is authorized.
- **Fact boundary:** Strategic plan items are planning targets/objectives unless verified by authorized institutional evidence. Do not interpret this matrix as registration, staffing, funding, partnership, or implementation evidence.

## 2. Coverage legend

| Status | Meaning |
|---|---|
| **Covered (Design)** | Architecture defines module/domain, key entities/workflow/permissions, and dependencies at Phase 1 design level. |
| **Partial** | Generic or partial architecture exists; domain-specific entities/workflow/controls/KPIs are incomplete. |
| **Missing** | No adequate domain architecture exists; only generic platform capability at most. |
| **Deferred** | Architecture intentionally gated by owner decision, privacy, provider, or future phase. |
| **Out of Scope (System)** | Physical/external activity; system may record evidence/metadata only. |

## 6. Explicit deferments and safeguards

- **OQ-49:** PARTIALLY RESOLVED — PENDING FORMAL APPROVAL; no ADR acceptance, no Phase 1 approval, no Phase 2 authorization.
- **OQ-24-29:** Privacy/safeguarding gate blocks sensitive beneficiary/protection/case schema, collection, and release.
- **OQ-01-06,31-35:** No invented institutional facts, no unverified assets/claims, no unpublished plan treated as public fact.
- **Finance/accounting:** No assumption of approved accounting system; finance domain is conceptual until owner/legal/policy decisions exist.
- **Physical/external activities:** System records metadata/evidence only (R-01-R-04 out-of-scope boundary preserved).
