## 4. القيود التقنية الموثقة

1. **محرك الهدف:** MySQL/MariaDB غير متاح في البيئة؛ التحقق على SQLite معزول فقط. لا يُدعى توافق نهائي مع محرك الإنتاج.
2. **المتصفح:** لا يوجد Dusk/Playwright مُثبّت؛ لا تحقق مرئي فعلي ولا لقطات شاشة.
3. **البناء:** تحذير `fontaine` الاختياري وتجاوز حزمة JS 500 kB؛ كلاهما غير قاتل وموثق.
4. **قاعدة التطوير:** لم تُطبَّق هجرات أو تحديثات على قاعدة مشتركة؛ أي تشغيل لاحق يحتاج إذناً منفصلاً.
5. **النشر:** لم يُنفَّذ أي deploy أو إدخال بيانات اعتماد حقيقية؛ بوابة §8 ما زالت مفتوحة.
6. **الاختبارات غير المتتبعة:** ملفات `tests/e2e/` لم تُشغّل ولم تُضمّن.
