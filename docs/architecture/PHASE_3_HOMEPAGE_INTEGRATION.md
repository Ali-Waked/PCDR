## What was preserved

- All homepage sections: intro splash, header/nav, hero, about, 11 strategic pillars, approach, program bento, 2027 targets, community roles, partnerships, knowledge cards, closing CTA, and footer.
- Arabic as the default/source text and all approved English `data-en` copy.
- Original navy/teal/sand/wheat palette and CSS custom properties.
- Animated logo SVG, logo PNGs, orbit/rays/wave/drawring hero treatment, scroll progress bar, marquee, staggered reveals, count-up statistics, and pointer effects.
- Logical CSS properties for RTL/LTR mirroring.
- Reduced-motion rules.
- Planning/status labels: 2027 figures remain planning targets, partnership categories remain aspirational, and knowledge cards remain demonstration content.

## Required adaptations

- The static `data-en` toggle is replaced with Inertia locale links so `/ar` and `/en` are real, crawlable routes with correct `lang`/`dir`.
- The original `fx.js` innerHTML word splitter is replaced by `SplitText.vue`, which renders trusted heading text as word spans without HTML injection.
- Styles are scoped under `.pcdr-home` so no other public or CMS page inherits the homepage design.
- SEO metadata is available in the server-rendered shell and then managed by Inertia; the homepage title matches the approved static source exactly.
- Motion listeners and observers are registered on mount and removed on unmount.

## Verification performed

- `npm run build`: passed with Vite 8.3.8; 630 modules transformed. Only warning is the optional `fontaine` fallback optimization, which does not affect output.
- Asset byte identity: all three logo files match the archive SHA-256 values.
- Served asset checks: PNG/SVG URLs return `200` with `image/png` / `image/svg+xml`.
- Copy fidelity check: 235 unique source strings extracted from `index.html`; 226 exact matches, with the remaining 9 accounted for by the source `<br>` heading representation (1) and zero-padded tile numbers generated by Vue (8).
- CSS parity: 21/21 keyframe names and 4/4 media-query conditions preserved; tokens, fonts, logical properties, reduced-motion rules, and RTL/LTR selectors present.
- Scoping check: all emitted homepage selectors include `.pcdr-home` or `.js/.ready .pcdr-home`; keyframes remain global as required.
- Locale shell: `/ar` returns `<html lang="ar" dir="rtl">`; `/en` returns `<html lang="en" dir="ltr">`.
- No headless browser binary is available in this environment, so responsive breakpoints, reduced-motion behavior, and pointer/mobile-nav interactions were verified by source/CSS inspection and production build, not by live screenshots.
