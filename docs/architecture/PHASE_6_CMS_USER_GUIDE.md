# دليل مستخدم نظام إدارة محتوى PCDR

**التاريخ:** 2026-11-23
**الجمهور:** محررو المحتوى والوسائط والاستفسارات داخل CMS.
**الحالة:** دليل تشغيلي تقني فقط؛ لا يمنح أي صلاحية موافقة مؤسسية.

---

## 1. قبل البدء

### 1.1 الدخول

- في الإنتاج، يوجّه نظام CMS الزائر غير المسجّل إلى صفحة الدخول الحقيقية للمرحلة الثانية `login.show`.
- واجهة الدخول المؤقتة المحلية (`cms.login`) معطّلة في الإنتاج؛ لا تحاول استخدامها هناك.
- الحساب هو حساب مستخدم PCDR العادي، وتُراجع الصلاحيات من الخادم قبل كل عملية.

### 1.2 الصلاحيات المطلوبة

| الإجراء | الصلاحية التقنية |
|---|---|
| عرض المحتوى/الصفحات/الأخبار | `pages.view` / `news.view` / الصلاحية المقابلة |
| تحرير المحتوى | `content.update` أو صلاحية الوحدة المحددة |
| مراجعة المحتوى | `content.review` |
| نشر المحتوى | `content.publish` |
| أرشفة المحتوى | `content.archive` |
| إدارة الوسائط | `media.view` / `media.create` / `media.update` / `media.delete` |
| عرض الاستفسارات | `inquiries.view` |
| تغيير حالة الاستفسار | `inquiries.update` |
| تعديل الإعدادات العامة | `settings.update` |

هذه صلاحيات تقنية للنظام، وليست تفويضاً مؤسسياً بالموافقة على المحتوى أو الأشخاص. لا توجد في النظام صلاحية `.approve`، ولم يُعيّن حاملو مناصب أو مفوّضون كتابياً حتى تاريخ هذا الدليل.

## 2. حالات المحتوى

الحالات المعتمدة تقنياً:

| الحالة | المعنى | الظهور على الموقع العام |
|---|---|---|
| `draft` | مسودة قيد التحرير | لا تظهر أبداً |
| `pending_review` | أُرسلت للمراجعة الداخلية | لا تظهر أبداً |
| `approved` | اجتازت المراجعة التقنية | لا تظهر حتى تُنشر |
| `published` | متاحة للجمهور | تظهر في الواجهة العامة |
| `archived` | مُؤرشفة | لا تظهر أبداً |

الانتقال بين الحالات يخضع لخريطة الانتقالات الموجودة في النظام وصلاحياتك. لا يمكن تجاوز النشر بالتعديل المباشر في الواجهة، ولا تظهر المسودة في الصفحة الرئيسية أو قوائم المحتوى العامة.

---

## 3. تحرير المحتوى

1. افتح قائمة المحتوى من الوحدة المطلوبة (صفحات، أخبار، مشاريع، إصدارات…).
2. اختر عنصراً موجوداً أو أنشئ عنصراً جديداً.
3. حرّر حقول اللغة العربية والإنجليزية بشكل مستقل. لا تفترض أن الترجمة تُنتج تلقائياً.
4. أدرج صورة من «منتقي الوسائط» عند الحاجة. المنتقي يعرض الصور العامة غير المقيدة فقط، وفقط إذا كان لديك `media.view`.
5. استخدم شريط الأدوات للتنسيق الأساسي: فقرات، عناوين، قوائم، اقتباس، رابط، جدول.
6. راجع «المعاينة» قبل الحفظ. المعاينة **نصية فقط**؛ لا تُعرض HTML خام داخل الواجهة.
7. احفظ. تُنشأ مراجعة (revision) تلقائياً في السجل عند تغيير الحالة أو المحتوى وفق السلوك الحالي.

### 3.1 قواعد النص المنسق

- الوسوم المسموحة هي ما يحدده `config('cms.editor.allowed_tags')` في الخادم.
- شريط الأدوات ينتج فقط وسوماً مسموحة؛ أي محتوى آخر يُطهَّر على الخادم.
- لا تستخدم المعاينة كدليل أمان؛ المطهّر الخادمي هو المرجع.
- لا تُدرج نصوصاً تحتوي أسراراً أو بيانات اعتماد أو معلومات شخصية غير مسموح بها.

---

## 4. مكتبة الوسائط

### 4.1 البحث والتصفية

- ابحث باسم الملف أو جزء منه عبر حقل البحث.
- صفِّ حسب النوع: `image` أو `document`.
- توضح القائمة العدد الإجمالي والصفحة الحالية والأخيرة.

### 4.2 الإضافة والتحرير

- ارفع صورة أو مستند من نوع مسموح.
- لكل لغة، املأ:
  - **النص البديل `alt_text`**: وصف موجز و دقيق للصورة لأغراض الوصولية.
  - **الوصف `caption`**: إن لزم، ويجب ألا يتحول إلى ادعاء مؤسسي غير معتمد.
- لا تعتبر الوسم المقيد (restricted) صالحاً للاستخدام في محرر المحتوى العام؛ لن يظهر في المنتقي.

### 4.3 المعاينة والحذف

- افتح «معاينة» للتأكد من الملف والنص البديل قبل إدراجه.
- الحذف يتطلب تأكيداً صريحاً؛ تأكد من عدم وجود المادة مستخدمة في محتوى منشور قبل الحذف.
- روابط التنزيل للوسائط المقيدة تخضع لآلية التوقيع والصلاحية الحالية؛ لم تُغيّر في هذه الحزمة.

## 5. الاستفسارات

تظهر الاستفسارات في ثلاث مجموعات منفصلة:

| المجموعة | المصدر |
|---|---|
| contact | رسائل التواصل العام |
| volunteer | طلبات التطوع |
| partnership | طلبات الشراكة |

### 5.1 التصفية والترقيم

- استخدم قائمة «الحالة» لتصفية النتائج، ثم اضغط تطبيق.
- كل مجموعة لها ترقيم صفحات مستقل وعرض لإجمالي النتائج.
- متابعة التصفية محفوظة في رابط الصفحة (`withQueryString`).

### 5.2 تغيير الحالة

الحالات التشغيلية المتاحة:

| الحالة | المعنى التشغيلي |
|---|---|
| `new` | وارد ولم يُعالج بعد |
| `in_progress` | قيد المتابعة الداخلية |
| `resolved` | أنجزت المعالجة التقنية |
| `closed` | أُغلق السجل التشغيلي |

للتغيير:

1. اختر المجموعة والسجل.
2. اختر الحالة الجديدة من القائمة.
3. اضغط «تحديث الحالة».
4. يظهر إشعار نجاح، وتُحدَّث القائمة.

تسجيلات الاستفسار قد تحتوي بيانات اتصال. تعامل معها كبيانات شخصية، ولا تنسخها إلى محتوى عام أو تقارير غير مخولة.

> **مهم:** تغيير حالة الاستفسار هو تسمية سير عمل داخلية فقط. لا يعني قبول المتطوع، أو اعتماد الشراكة، أو موافقة مؤسسية، أو إنشاء تعيين/تفويض. أي قرار من هذا النوع يخضع لعملية مؤسسية منفصلة لم تُفعّل في النظام.

---

## 6. ما لا يفعله هذا الدليل

- لا يحدد أسماء أصحاب المناصب أو المفوضين.
- لا يمنح حق الموافقة على ADR أو تغيير حالة OQ أو بدء مرحلة جديدة.
- لا يجيز نشر ادعاءات مؤسسية غير موثقة (تاريخ تأسيس، أرقامregistration، شركاء، نتائج).
- لا يجيز تصدير بيانات المستفيدين أو تفعيل قنوات خارجية أو إرسال جماعي.

---

## 7. استكشاف الأخطاء

| العَرَض | السبب المحتمل | التصرف |
|---|---|---|
| وصول إلى 404 عند فتح CMS في الإنتاج | محاولة استخدام بوابة cms.login المؤقتة | سجّل الدخول من مسار المرحلة الثانية `login.show` |
| منتقي الوسائط فارغ | لا توجد صور عامة، أو لا تملك `media.view` | راجع الصلاحية أو ارفع صورة عامة، ولا تستخدم وسائط مقيدة |
| فشل تغيير حالة استفسار | لا تملك `inquiries.update` أو قيمة الحالة غير مسموحة | راجع الصلاحية واختر إحدى الحالات الأربع |
| لا يظهر المحتوى في الموقع | الحالة ليست `published`، أو الترجمة مطلوبة | راجع الحالة واللغة قبل النشر |
| تحذير حجم الحزمة أثناء البناء | تحذير Vite غير قاتل | لا يمنع استخدم الواجهة؛ يُسجّل في تقرير البناء |
